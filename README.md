# IoT-smart-energy-monitoring-system-for-buildings

An IoT-Based Smart Energy Monitoring System for Buildings that uses ESP32 and PZEM-004T sensors to measure electricity consumption in real time. It displays voltage, current, power, and energy usage on a dashboard through Wi-Fi, helping users monitor consumption, estimate costs, and reduce energy wastage.

The IoT-Based Smart Energy Monitoring System for Buildings is designed to monitor and track electricity consumption in real time. The system uses an ESP32 microcontroller along with a PZEM-004T energy monitoring sensor to measure important electrical parameters such as voltage, current, power, and energy consumption. These components work together to collect accurate information about the electricity being used.

The collected data is transmitted through Wi-Fi using the ESP32 and displayed on a user-friendly dashboard through the Blynk Cloud platform. This allows users to view real-time electricity readings and monitor energy usage conveniently. The dashboard helps users understand their electricity consumption without needing to check the electrical meter manually.

The main objective of this project is to improve energy monitoring and encourage efficient electricity usage in buildings. By providing continuous information about power consumption and estimated electricity costs, the system helps users identify unnecessary energy usage and reduce wastage. Overall, this project offers a simple, cost-effective, and IoT-based solution for smart energy management.
